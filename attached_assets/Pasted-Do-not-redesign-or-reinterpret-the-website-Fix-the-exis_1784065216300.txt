Do not depend on .htaccess for basic navigation. Every navigation link must point to a real HTML file.

visibility: hidden;
transform: translateY(...);

Fade effects may be progressively enhanced, but the default HTML and CSS state must always be visible.

Preserve the original website’s visual design. Do not substitute new fonts, generic spacing, alternate images, changed colors, or a new layout merely because the site is being converted to static HTML.
Use the original application’s existing CSS values and assets as the basis for the static version. Extract the actual rendered styles rather than manually approximating them.
