1. Simplify the main Patent Infringement Monitor project page

The current project workspace exposes too much operational detail at once.

Replace the main workspace with a compact portfolio-style dashboard.

2. Monitoring status

Add a prominent monitoring control for every patent.

Use:

Active

Paused

These statuses are independent from whether the patent remains part of the project.

An Active patent is eligible for future scheduled/automated infringement monitoring.

A Paused patent remains in the project with all historical information intact but should not be included in future automated/scheduled monitoring runs.

ADMIN and ATTORNEY should be able to change this directly from the dashboard.

CLIENT users should only be allowed to change monitoring state if their permissions explicitly allow it. Otherwise they should see the current state read-only.

Do not delete analysis history when monitoring is paused.
