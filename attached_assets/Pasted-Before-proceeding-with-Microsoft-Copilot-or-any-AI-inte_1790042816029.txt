application/prosecution status; and
patent grant/issue status.

A patent imported by an issued U.S. patent number and confirmed by USPTO grant XML must not be labeled Pending merely because some USPTO File Wrapper field refers to an application/prosecution status.

For the patent detail and Claim Analysis pages, use a clear patent-level status model such as:

Issued
Expired
Lapsed
Canceled/Disclaimed, if reliably determinable
Pending only for an actually pending application
Unknown where the available USPTO data does not reliably establish status

Do not infer expiration, enforceability, validity, terminal-disclaimer effects, maintenance-fee status, or other legal conclusions unless the USPTO source being used reliably supports that conclusion.

At minimum, if the system has retrieved an official USPTO patent grant with an issue date, the UI should identify the record as Issued, rather than Pending.
