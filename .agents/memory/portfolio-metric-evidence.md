---
name: Portfolio metric evidence
description: Evidence and disclosure rules for public USPTO portfolio analytics.
---

For public portfolio intelligence, publish only metrics with traceable source fields. Disclose cohort size and date range for sample-based metrics; do not infer counsel identity from correspondence text or continuation relationships without structured, validated family fields. Show “unavailable” rather than estimates when those fields are not supported.

**Why:** Unsupported inference can turn incomplete public records into misleading portfolio advice.

**How to apply:** Show denominators and filing-date ranges for prosecution samples. Add counsel or family analytics only when the source provides structured, validated identity or relationship fields.
