name: Public tool directory
description: Product direction for an expanding collection of complimentary patent tools.
---

The AI Tools page is intended to grow beyond the portfolio and examiner tools. Keep the directory extensible and avoid copy or layout that assumes exactly two tools.

**Why:** The user explicitly plans to add other tools. Visitors were confused about where to click; the user confirmed the distinct button-style cards were better.

**How to apply:** Preserve clear, clickable tool cards, explicit action labels, and selected-state guidance as the collection grows. New tools should use the same directory pattern rather than require a separate page redesign.

Keep single-company analysis separate from company comparison. The requested order is Patent Portfolio Analyzer, Patent Portfolio Comparison, then Patent Examiner Intelligence.

**Why:** The user explicitly moved the embedded comparison feature into its own tool and specified comparison as tool #2.

**How to apply:** Do not reintroduce comparison actions into the single-company analyzer. Preserve both companies' scope selection and simultaneous result reveal. The comparison PDF is a consolidated report, not an individual-company chooser.

The comparison tool should show first-company and second-company inputs together, rather than collect the second company through a separate search popup.

**Why:** The user explicitly requested two visible company fields after trying the sequential workflow.

**How to apply:** Keep both names editable in the main comparison form; use popups only to resolve the applicant names belonging to each company.
